============================================================
1. <!DOCTYPE html>
============================================================

Kode:

<!DOCTYPE html>

Kegunaan:

Memberi tahu browser bahwa dokumen menggunakan HTML5.

Tujuannya agar browser menggunakan standard mode HTML modern.

Kode ini bukan sebuah tag HTML biasa, tetapi deklarasi tipe
dokumen.

Eksperimen:

- Hapus <!DOCTYPE html>
- Commit perubahan
- Lihat apakah tampilan website berubah
- Pasang kembali

Pada browser modern mungkin tidak terlihat perbedaannya,
tetapi deklarasi ini tetap penting untuk memastikan browser
menggunakan standard mode.


============================================================
2. <html lang="en">
============================================================

Kode:

<html lang="en">

Elemen <html> adalah pembungkus utama seluruh dokumen HTML.

Semua isi halaman berada di dalam:

<html>
    ...
</html>

Atribut:

lang="en"

Memberi tahu browser dan teknologi lain bahwa bahasa utama
dokumen adalah Bahasa Inggris.

Jika website menggunakan Bahasa Indonesia:

<html lang="id">

Jadi:

lang="en"
= bahasa utama halaman adalah English.

lang="id"
= bahasa utama halaman adalah Bahasa Indonesia.

Atribut lang bukan alat untuk menerjemahkan halaman.

Fungsinya memberikan informasi bahasa kepada browser,
screen reader, search engine, dan teknologi lainnya.

Contoh halaman utama Bahasa Indonesia tetapi ada bagian
Bahasa Inggris:

<html lang="id">

    <p>Halo, saya Rama.</p>

    <p lang="en">
        I enjoy experimenting with Linux.
    </p>

</html>

============================================================
4. <meta charset="UTF-8">
============================================================

Kode:

<meta charset="UTF-8">

Menentukan encoding karakter yang digunakan halaman.

UTF-8 memungkinkan halaman memahami banyak jenis karakter,
misalnya:

é
©
→
🐧
日本語
العربية

Kalau encoding tidak sesuai, karakter tertentu bisa
ditampilkan secara aneh.

Eksperimen:

- Hapus <meta charset="UTF-8">
- Commit
- Lihat hasilnya
- Pasang kembali

Browser modern mungkin tetap menampilkan halaman dengan benar,
tetapi UTF-8 tetap sebaiknya digunakan.


============================================================
5. Viewport
============================================================

Kode:

<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

Ini penting untuk tampilan responsive, terutama di perangkat
mobile.

Bagian:

width=device-width

Artinya lebar halaman mengikuti lebar layar perangkat.

Contoh:

Laptop -> layar lebar
HP     -> layar lebih kecil

Bagian:

initial-scale=1.0

Menentukan zoom awal halaman sebesar 100%.

Tanpa viewport yang benar, website yang terlihat bagus di
desktop bisa terlihat aneh ketika dibuka melalui HP.

============================================================
7. Menghubungkan HTML dengan CSS
============================================================

Kode:

<link rel="stylesheet" href="./style.css">

Ini adalah salah satu bagian penting dari project.

HTML dan CSS berada di file yang berbeda.

index.html
    |
    | <link>
    v
style.css

Bagian:

rel="stylesheet"

Memberi tahu browser bahwa file yang dihubungkan adalah
stylesheet/CSS.

Bagian:

href="./style.css"

Menentukan lokasi file CSS.

"./"

berarti dari folder tempat file HTML berada.

Struktur project:

portfolio/
├── index.html
├── style.css
├── script.js
└── assets/

Maka:

./style.css

berarti:

portfolio/style.css

Kalau lokasi atau nama file salah, CSS tidak akan diterapkan.

============================================================
13. <div>
============================================================

Contoh:

<div class="nav-links">

<div> adalah container generik.

<div> sendiri tidak mempunyai arti khusus seperti <nav>,
<header>, atau <footer>.

Fungsinya adalah mengelompokkan elemen.

Contoh:

<div class="nav-links">

    <a href="#about">About</a>
    <a href="#projects">Projects</a>
    <a href="#skills">Skills</a>
    <a href="#contact">Contact</a>

</div>

CSS kemudian bisa menargetkan:

.nav-links {
    ...
}

Atribut:

class="nav-links"

memberikan nama kelompok kepada elemen agar bisa ditargetkan
oleh CSS atau JavaScript.

14. <a> dan href
============================================================

Contoh:

<a href="#about">About</a>

<a>
= anchor/link

href
= tujuan link

Ada dua jenis tujuan yang digunakan dalam portfolio.

Pertama:

href="#about"

Ini menuju bagian lain dalam halaman yang mempunyai:

id="about"

Contoh:

<a href="#about">About</a>

        |
        v

<section id="about">

Tanda "#" menunjukkan bahwa tujuan tersebut adalah ID dalam
halaman yang sama.

Kedua:

<a href="https://github.com/Mora-project-ui">

Ini menuju website/URL lain.

Jadi:

#about
= tujuan internal dalam halaman

https://...
= URL

============================================================

Contoh:

>

<img> digunakan untuk menampilkan gambar.

Atribut:

src
= lokasi gambar

alt
= teks alternatif gambar

class
= nama class untuk styling atau pengelompokan


------------------------------------------------------------
17.1 src
------------------------------------------------------------

Kode:

src="./assets/RAMA-BLACK-STYLE.jpg"

Menentukan lokasi file gambar.

Struktur:

portfolio/
├── index.html
└── assets/
    └── RAMA-BLACK-STYLE.jpg

Maka:

./assets/RAMA-BLACK-STYLE.jpg

adalah lokasi yang benar.


------------------------------------------------------------
17.2 alt
------------------------------------------------------------

Kode:

alt="Mohammad Rama"

Alternative text atau teks alternatif.

Jika gambar gagal dimuat, alt dapat membantu memberikan
informasi mengenai gambar tersebut.

Alt juga berguna untuk accessibility seperti screen reader.


------------------------------------------------------------
17.3 class
------------------------------------------------------------

Kode:

class="profile-image"

Menghubungkan elemen HTML dengan aturan CSS.

HTML:

<img class="profile-image">

CSS:

.profile-image {
    width: 140px;
    height: 140px;
}

Jadi HTML menentukan elemen mana yang ingin diberi style,
sedangkan CSS menentukan bagaimana tampilannya.

29. 5 KONSEP PALING PENTING
============================================================

Tidak perlu menghafalkan semua tag.

Yang paling penting untuk dipahami:

------------------------------------------------------------
1. HTML = STRUKTUR
------------------------------------------------------------

Contoh:

<section>
    <h2>Projects</h2>

    <p>
        Daftar project saya.
    </p>
</section>

HTML menentukan apa yang ada di halaman.


------------------------------------------------------------
2. CSS = TAMPILAN
------------------------------------------------------------

Contoh:

section {
    padding: 100px;
}

CSS menentukan bagaimana elemen tersebut terlihat.


------------------------------------------------------------
3. class = IDENTITAS KELOMPOK
------------------------------------------------------------

HTML:

<span class="profile-image">

CSS:

.profile-image {
    ...
}

Class biasanya digunakan ketika kita ingin memberikan style
kepada satu atau beberapa elemen yang memiliki karakteristik
yang sama.

Satu class dapat digunakan oleh banyak elemen.


------------------------------------------------------------
4. id = IDENTITAS SPESIFIK
------------------------------------------------------------

HTML:

<section id="projects">

Bisa dituju:

<a href="#projects">Projects</a>

Bisa ditargetkan CSS:

#projects {
    ...
}

ID biasanya digunakan untuk identitas unik sebuah elemen.


------------------------------------------------------------
5. src dan href
------------------------------------------------------------

<img src="./assets/linux.svg">

src
= mengambil/menentukan lokasi file yang digunakan oleh elemen.

Sedangkan:

<a href="https://github.com/...">

href
= menentukan tujuan link.

Gampangnya:

src
= "Ambil dari mana?"

href
= "Pergi ke mana?"


============================================================
30. HUBUNGAN HTML DAN CSS
============================================================

Contoh:

HTML:

<img class="profile-image">

CSS:

.profile-image {
    width: 140px;
    height: 140px;
    border-radius: 50%;
}

HTML mengatakan:

"Ini adalah gambar profile."

CSS mengatakan:

"Buat gambar profile ini berukuran 140x140,
berbentuk bulat, dan memiliki style tertentu."

Jadi:

HTML
    ↓
menentukan struktur

CSS
    ↓
mengatur tampilan

31. EKSPERIMEN BELAJAR
============================================================

Tujuan eksperimen bukan sekadar membuat website berubah.

Tujuannya adalah belajar memprediksi:

"Kalau kode ini gue ubah, apa yang akan terjadi?"

------------------------------------------------------------
Eksperimen 1
------------------------------------------------------------

Ubah:

<h1>Mohammad Rama al-jannah</h1>

menjadi:

<h1>MORA PROJECT UI</h1>

Lihat perubahan pada halaman.

------------------------------------------------------------
Eksperimen 2
------------------------------------------------------------

Hapus:

<link rel="stylesheet" href="./style.css">

Commit.

Lihat website.

Kemudian pasang kembali.

Tujuan:

Memahami perbedaan HTML dan CSS secara langsung.

------------------------------------------------------------
Eksperimen 3
------------------------------------------------------------

Ubah:

href="#about"

menjadi:

href="#contact"

Klik link About.

Perhatikan section yang dibuka.

Tujuan:

Memahami hubungan href="#..." dengan id="...".

------------------------------------------------------------
Eksperimen 4
------------------------------------------------------------

Ubah:

class="profile-image"

menjadi:

class="test"

Jangan ubah CSS.

Lihat apa yang terjadi pada gambar profile.

Tujuan:

Memahami hubungan antara class HTML dan selector CSS.

------------------------------------------------------------
Eksperimen 5
------------------------------------------------------------

Cari CSS:

.skills-list span

Ubah:

border-radius: 999px;

menjadi:

border-radius: 0;

Lihat perubahan bentuk badge.

Tujuan:

Memahami bagaimana CSS mengubah tampilan elemen HTML.

------------------------------------------------------------
Eksperimen 6
------------------------------------------------------------

Ubah:

gap: 12px;

menjadi:

gap: 30px;

Lihat jarak antar badge.

Tujuan:

Memahami fungsi property gap.
