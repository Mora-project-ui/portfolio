============================================================
1. UNIVERSAL SELECTOR *
============================================================

Kode:

* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

Tanda:

*

disebut universal selector.

Artinya CSS ini berlaku untuk semua elemen HTML.

Contoh:

* {
    margin: 0;
}

berarti margin semua elemen di-reset menjadi 0.


------------------------------------------------------------
margin: 0;
------------------------------------------------------------

Margin adalah jarak bagian luar sebuah elemen.

Contoh:

[ margin ]
[  elemen  ]
[ margin ]

Dengan:

margin: 0;

browser tidak memberikan margin default pada elemen tersebut.


------------------------------------------------------------
padding: 0;
------------------------------------------------------------

Padding adalah jarak antara isi elemen dengan batas/border
elemen tersebut.

Gampangnya:

margin
= jarak di luar elemen

padding
= jarak di dalam elemen


------------------------------------------------------------
box-sizing: border-box;
------------------------------------------------------------

Ini mengubah cara browser menghitung ukuran elemen.

Dengan:

box-sizing: border-box;

width dan height yang diberikan sudah termasuk:

content
+ padding
+ border

Ini membuat pengaturan ukuran elemen lebih mudah diprediksi.

Tanpa border-box, padding dan border dapat menambah ukuran
total elemen di luar width/height yang diberikan.


============================================================
2. html
============================================================

Kode:

html {
    scroll-behavior: smooth;
}

Menargetkan elemen <html>.

Property:

scroll-behavior: smooth;

membuat perpindahan halaman ketika menggunakan anchor link
menjadi halus.

Contoh HTML:

<a href="#contact">Contact</a>

Ketika diklik, browser tidak langsung melompat secara kasar
ke bagian Contact.

Dengan:

scroll-behavior: smooth;

perpindahannya menjadi smooth.


------------------------------------------------------------
Eksperimen
------------------------------------------------------------

Ubah:

scroll-behavior: smooth;

menjadi:

scroll-behavior: auto;

Kemudian klik link navbar.

Bandingkan perbedaannya.

3. body
============================================================

Kode:

body {
    font-family: Arial, sans-serif;
    background: #0f1115;
    color: #ffffff;
    line-height: 1.6;
}

body adalah seluruh area utama halaman.


------------------------------------------------------------
font-family
------------------------------------------------------------

Kode:

font-family: Arial, sans-serif;

Menentukan jenis font.

Arial adalah font utama.

sans-serif adalah fallback.

Artinya jika Arial tidak tersedia, browser menggunakan font
jenis sans-serif lainnya.


------------------------------------------------------------
background
------------------------------------------------------------

Kode:

background: #0f1115;

Menentukan warna background halaman.

#0f1115 adalah warna dalam format hexadecimal.

Contoh:

#ffffff
= putih

#000000
= hitam

#0f1115
= warna gelap yang digunakan portfolio.


------------------------------------------------------------
color
------------------------------------------------------------

Kode:

color: #ffffff;

Menentukan warna teks default.

Karena berada di body, elemen teks yang tidak mempunyai warna
sendiri biasanya akan mewarisi warna ini.


------------------------------------------------------------
line-height
------------------------------------------------------------

Kode:

line-height: 1.6;

Mengatur jarak vertikal antar baris teks.

Semakin besar nilainya, semakin renggang jarak antar baris.

Contoh:

line-height: 1;

lebih rapat.

line-height: 1.6;

lebih nyaman untuk paragraf.

5. header
============================================================

Kode:

header {
    position: sticky;
    top: 0;
    z-index: 1000;

    background: rgba(15, 17, 21, 0.9);
    border-bottom: 1px solid #252932;
    backdrop-filter: blur(10px);
}

Selector:

header

menargetkan:

<header>

di HTML.


------------------------------------------------------------
position: sticky;
------------------------------------------------------------

Membuat header dapat tetap berada di posisi atas ketika
halaman di-scroll.

Berbeda dengan position: static biasa.

Sticky membuat elemen mengikuti scroll sampai batas tertentu.


------------------------------------------------------------
top: 0;
------------------------------------------------------------

Menentukan posisi sticky dari bagian atas.

top: 0;

berarti:

"Tempelkan elemen pada posisi 0 dari atas."


------------------------------------------------------------
z-index: 1000;
------------------------------------------------------------

Mengatur urutan tumpukan elemen.

Semakin tinggi nilai z-index, biasanya elemen berada di depan
elemen lain yang memiliki stacking context yang sama.

1000 digunakan agar navbar tetap berada di atas konten.


------------------------------------------------------------
background: rgba(...)
------------------------------------------------------------

Kode:

background: rgba(15, 17, 21, 0.9);

rgba terdiri dari:

R = Red
G = Green
B = Blue
A = Alpha/transparency

Angka terakhir:

0.9

berarti tingkat opacity/transparansi.

1.0 = sepenuhnya opaque
0.0 = transparan

Jadi background navbar sedikit transparan.


------------------------------------------------------------
border-bottom
------------------------------------------------------------

Kode:

border-bottom: 1px solid #252932;

Memberikan garis pada bagian bawah navbar.

Struktur:

border-bottom:
    1px      -> ketebalan
    solid    -> jenis garis
    #252932  -> warna


------------------------------------------------------------
backdrop-filter
------------------------------------------------------------

Kode:

backdrop-filter: blur(10px);

Memberikan efek blur pada area di belakang elemen.

Karena background navbar dibuat transparan, efek ini membuat
navbar terlihat seperti kaca/blur.

12. #hero
============================================================

Kode:

#hero {
    min-height: 85vh;

    display: flex;
    flex-direction: column;
    justify-content: center;
}

Tanda:

#

digunakan untuk selector ID.

Jadi:

#hero

menargetkan:

<section id="hero">


------------------------------------------------------------
min-height: 85vh;
------------------------------------------------------------

vh = viewport height.

85vh berarti minimal tinggi section adalah 85% tinggi layar.

Jika tinggi layar:

100vh

maka:

85vh
= 85% tinggi viewport.


------------------------------------------------------------
display: flex;
------------------------------------------------------------

Mengaktifkan Flexbox.


------------------------------------------------------------
flex-direction: column;
------------------------------------------------------------

Mengubah arah Flexbox menjadi vertikal.

Tanpa ini, default flex-direction adalah:

row

Dengan:

column

elemen disusun:

foto
Hello
nama
subtitle
deskripsi


------------------------------------------------------------
justify-content: center;
------------------------------------------------------------

Memposisikan isi flex di tengah pada arah utama.

Karena direction = column, arah utamanya adalah vertikal.

Jadi isi Hero berada di tengah secara vertikal.

clamp()
------------------------------------------------------------

Kode:

clamp memiliki tiga nilai:

clamp(minimum, preferred, maximum)

Jadi:

minimum = 40px
preferred = 7vw
maximum = 72px

Ukuran font dapat menyesuaikan layar tetapi tidak akan
lebih kecil dari 40px atau lebih besar dari 72px.


------------------------------------------------------------
vw
------------------------------------------------------------

vw = viewport width.

7vw berarti 7% dari lebar viewport.


------------------------------------------------------------
line-height
------------------------------------------------------------

Kode:

line-height: 1.1;

Mengatur tinggi/jarak antar baris.

34. @media
============================================================

Kode:

@media (max-width: 700px) {

    ...

}

Ini adalah media query.

Media query digunakan untuk memberikan CSS berbeda
berdasarkan kondisi perangkat atau ukuran layar.

Di sini:

max-width: 700px

berarti aturan di dalamnya aktif ketika lebar viewport
maksimal 700px.

Biasanya digunakan untuk layar HP atau layar kecil.

Pada layar kecil ukuran h1 dibuat lebih kecil.

clamp(40px, 7vw, 72px)

Sedangkan mobile diberikan:

42px

Supaya nama tidak terlalu besar pada layar HP.

42. KONSEP CSS PALING PENTING
============================================================

Beberapa konsep yang perlu dipahami:

------------------------------------------------------------
SELECTOR
------------------------------------------------------------

Menentukan elemen mana yang akan diberi style.

Contoh:

body

header

nav a

article

------------------------------------------------------------
CLASS SELECTOR
------------------------------------------------------------

Diawali dengan:

.

.profile-image

.skills-list

class="profile-image"

class="skills-list"


------------------------------------------------------------
ID SELECTOR
------------------------------------------------------------

Diawali dengan:

#

Contoh:

#hero

#projects

#contact

Menargetkan:

id="hero"

id="projects"

id="contact"


------------------------------------------------------------
ELEMENT SELECTOR
------------------------------------------------------------

Contoh:

body

header

article

footer

Menargetkan elemen HTML langsung.


------------------------------------------------------------
DESCENDANT SELECTOR
------------------------------------------------------------

Contoh:

nav a

Artinya:

semua <a> yang berada di dalam <nav>.


------------------------------------------------------------
CHILD SELECTOR
------------------------------------------------------------

Contoh:

section > h2

Tanda:

>

berarti child langsung.

Artinya:

<h2> yang merupakan child langsung dari <section>.

============================================================
46. CSS CASCADE
============================================================

CSS berarti:

Cascading Style Sheets.

Salah satu konsep penting adalah ketika beberapa aturan
CSS dapat memengaruhi elemen yang sama.

Contoh:

p {
    color: white;
}

#about p {
    color: green;
}

Paragraf di dalam #about akan mendapatkan aturan yang lebih
spesifik dari:

#about p

dibanding:

p

Jadi memahami selector dan specificity penting ketika website
semakin kompleks.


============================================================
47. HUBUNGAN HTML DAN CSS
============================================================

Contoh:

HTML:

<span class="skills-list">
    ...
</span>

CSS:

.skills-list {
    display: flex;
}

HTML menentukan:

"Elemen ini memiliki class skills-list."

CSS kemudian mengatakan:

"Elemen dengan class skills-list ditampilkan menggunakan
Flexbox."


Contoh lain:

HTML:

<img class="profile-image">

CSS:

.profile-image {
    width: 140px;
    border-radius: 50%;
}

HTML = struktur

CSS = tampilan
